# Random Password Generator

## Project Description

This is a Python-based Random Password Generator that generates random passwords based on the length entered by the user.

## Features

- Generates random passwords.
- Includes uppercase and lowercase letters.
- Includes numbers and special characters.
- Validates password length.
- Handles invalid inputs using try-except.

## Technologies Used

- Python
- Random Module
- String Module

## How to Run

1. Install Python.
2. Open the project folder in VS Code.
3. Run the following command:

```bash
python password_generator.py
```

4. Enter the required password length.
5. The program generates a random password.

## Error Handling

- Displays an error message for zero or negative length.
- Handles non-numeric inputs.
